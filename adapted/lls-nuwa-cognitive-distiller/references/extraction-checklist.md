# 认知蒸馏证据检查表

## 来源优先级

| 等级 | 材料 | 用途 |
|---|---|---|
| A | 本人著作、完整演讲、长访谈、官方文章 | 建立核心模型 |
| B | 可核验决策、长期项目、公开复盘 | 验证模型是否影响行动 |
| C | 合作者、批评者、可靠传记 | 寻找反例和盲区 |
| D | 二手摘要、短视频切片、转述 | 只作线索，不直接定论 |

## 模型进入门槛

- 至少两个独立场景出现；
- 能解释一个真实选择；
- 能预测一个新问题的判断方向；
- 与普通常识有可说明的差异；
- 已记录冲突证据与适用范围。

## 公开前检查

- 引文有来源和上下文；
- 推断使用明确标签；
- 未复制大段受版权保护内容；
- 未包含私人聊天、付费课程原文或内部资料；
- Skill 的名字、slug 和来源说明完整。
