# 罗老师女娲认知蒸馏器

- **当前源码版本：`1.0.0`**（最近 Release：`1.0.0`）

从公开资料中提取人物或主题的心智模型、判断规则、表达结构、反模式与诚实边界，并生成可验证的 Skill 蓝图。

## 适合谁

- 想研究公开人物思考方式的学习者；
- 想制作人物视角 Skill 的创作者；
- 需要把“像某人说话”升级为“按某套框架判断”的团队。

## 快速调用

```text
请使用 lls-nuwa-cognitive-distiller，蒸馏“对象在某个领域的思考方法”，先做来源矩阵，再生成 Skill 蓝图和测试题。
```

- **Skill slug：`lls-nuwa-cognitive-distiller`**

把下面内容粘贴到 WorkBuddy 新会话：

```text
请按 https://skillhub.cn/install/skillhub.md 检查 SkillHub，搜索 `lls-nuwa-cognitive-distiller`；仅在 slug 完全一致时安装到 `~/.workbuddy/skills/`。安装后读取 `~/.workbuddy/skills/lls-nuwa-cognitive-distiller/SKILL.md`，核对 name、version 和实际路径，然后新开会话触发该 Skill。
```

也可以打开左侧「技能」→「添加技能 / 查找技能」，搜索 `lls-nuwa-cognitive-distiller` 后安装；界面文字可能随 WorkBuddy 版本变化。
