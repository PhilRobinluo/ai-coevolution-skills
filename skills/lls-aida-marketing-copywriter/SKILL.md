# 罗老师 AIDA 营销文案助手

## AIDA 不是四段套话

AIDA 的四步分别承担不同任务：

- **Attention**：让真正相关的人停下来；
- **Interest**：证明你理解他的处境；
- **Desire**：用价值、证据和取舍建立期待；
- **Action**：让下一步清楚、真实、低摩擦。

它不是“震惊开头 + 疯狂制造焦虑 + 立即购买”。

## 一、建立事实底稿

在写文案前填：

```text
产品/服务：
目标受众：
发生场景：
要解决的问题：
具体能力：
真实证据：
适用范围：
不适用情况：
价格/条件：
目标行动：
发布渠道：
```

所有数字、案例、评价和结果必须有来源。没有证据的利益点写成假设或删除。

## 二、理解受众任务

不要只写“25–35 岁职场人”，而要写：

- 他此刻正在做什么；
- 哪一步最费力；
- 过去试过什么；
- 为什么仍未解决；
- 他担心的风险；
- 他用什么标准选择。

营销文案应帮助用户判断是否适合，而不是隐藏选择成本。

## 三、写 Attention

有效开头来自相关性：

- 具体场景；
- 可验证结果；
- 明确问题；
- 反直觉但有证据的判断；
- 用户刚发生的动作。

检查开头：

- 是否只吸引目标受众；
- 正文能否兑现；
- 是否依赖恐吓、羞辱或虚假数字；
- 去掉夸张词后是否仍有信息。

## 四、写 Interest

兴趣段回答“为什么值得继续看”：

1. 用一到两句复述真实处境；
2. 指出旧方法的具体成本；
3. 说明问题形成机制；
4. 引出方案，但不立即堆功能。

优先使用用户语言、真实流程和细节。避免“在这个快速变化的时代”等空背景。

## 五、写 Desire

将功能翻译成使用价值：

```text
功能 → 用户动作变化 → 可观察结果 → 证据 → 限制
```

例如：

```text
自动生成任务表
→ 会后少一次手工整理
→ 负责人和日期更容易核对
→ 来自实际工作流演示
→ 仍需人工确认责任归属
```

渴望不是保证结果。呈现适用条件、投入和取舍会增加可信度。

可用证据：

- 产品演示；
- 可复现过程；
- 有口径的案例；
- 客户授权评价；
- 第三方测试；
- 公开文档。

## 六、写 Action

行动要匹配用户所处阶段：

- 了解阶段：查看示例、下载清单；
- 比较阶段：看规格、预约演示；
- 决策阶段：试用、报名、购买；
- 高风险或高价格：先咨询、确认适用条件。

行动区包含：

- 做什么；
- 得到什么；
- 需要投入什么；
- 截止或数量信息是否真实；
- 数据、退款或后续联系说明。

## 七、适配渠道

### 信息流广告

快速建立相关性，单一主张，链接落地页承接完整证据。

### 落地页

允许完整展示问题、方案、证据、适用范围、常见问题和行动。

### 私域消息

尊重关系和频率，先说明为什么发给对方，提供退出或忽略空间。

### 海报

只保留主信息、关键证据和行动入口；详细条件移到说明页。

### 视频

口语化、按时间兑现承诺，证据最好可被画面看到。

## 输出格式

- 事实底稿与缺口；
- 受众任务；
- AIDA 结构表；
- 主版本文案；
- 两个不同 Attention 版本；
- 证据与限制清单；
- 行动区；
- 渠道适配版；
- 合规和真实性检查。

## 质量门禁

- [ ] 所有利益点能追溯到产品事实；
- [ ] 开头与正文承诺一致；
- [ ] 没有伪造评价、数字、倒计时或库存；
- [ ] 没有羞辱、恐吓和歧视性画像；
- [ ] 适用范围与重要限制可见；
- [ ] CTA 说明行动、价值和成本；
- [ ] 隐私和联系权限得到尊重；
- [ ] 文案可以用真实渠道指标进行测试；
- [ ] A/B 测试一次只改变一个主要变量。
