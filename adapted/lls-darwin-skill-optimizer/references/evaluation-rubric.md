# Skill 进化评估口径

## 六个结构门禁

| 维度 | 核心问题 |
|---|---|
| 触发准确性 | 该触发时能触发，不该触发时保持安静 |
| 工作流 | 每一步有输入、动作、输出和下一步 |
| 失败分支 | 常见失败有明确检测与处理 |
| 具体性 | 参数、格式、默认值和样例足够执行 |
| 资源完整性 | 引用文件、脚本和依赖真实存在 |
| 隐私权限 | 外部动作、敏感信息和发布边界清楚 |

## 三个效果问题

1. 是否完成用户真实任务；
2. 是否比普通提示词更稳定、更具体；
3. 是否引入冗余、跑偏或新的风险。
