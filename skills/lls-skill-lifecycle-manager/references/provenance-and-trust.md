# 来源、版权与信任

## 三层来源

### 🔵 LLS Original

- 罗老师原创并持续维护。
- 可以提供源码、安装包和中文说明。
- 在机器目录中标记 `lls-original`。

### 🟡 LLS Adapted

必须保留：

- 原作者和原始仓库
- 原始许可证和版权声明
- 上游版本或提交
- 修改内容和改编版本
- 上游要求保留的 LICENSE / NOTICE

许可状态不清时不进入改编区。

### 🟢 Community Pick

默认只保存：

- 名称、作者、用途和分类
- 原始仓库
- 许可证状态
- 核验版本和日期
- 推荐理由
- 适用平台

安装工具直接从原作者仓库的固定版本下载，不复制源码。

## 精选门槛

1. 作者、来源和许可证状态清楚；
2. 安装测试通过；
3. 用途具体；
4. 未发现明显凭证和隐私风险；
5. 最近仍可使用；
6. 推荐理由来自真实测试；
7. 记录最后核验日期。

## 双重 Star

先写：

> 这个 Skill 由原作者创作，请优先前往原仓库给作者一个 ⭐ Star。

再写：

> 如果你认可罗老师的筛选、测试和中文说明，也欢迎 ⭐ Star 本导航仓库。

Star 代表收藏与支持；Watch Releases 才是版本通知。
