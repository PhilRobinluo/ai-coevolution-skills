# 罗老师同事经验蒸馏器

- **当前源码版本：`1.0.0`**（最近 Release：`1.0.0`）

把同事、导师或岗位的工作流程、判断标准、质量门禁和交付习惯整理成可复用 Skill，并保持内部资料与公开版本隔离。

## 快速调用

```text
请使用 lls-colleague-skill-distiller，把一个岗位的工作方法蒸馏成 Skill。先做岗位地图和隐私边界，再使用合成案例测试。
```

## 重要原则

- 默认蒸馏岗位能力，不追求完整人格复制；
- 内部资料生成的 Skill 留在私有工作区；
- 公开版使用合成案例独立重写；
- 发布前同时检查源码、截图、附件、Git 历史和 ZIP。

## 在 WorkBuddy 安装

- **Skill slug：`lls-colleague-skill-distiller`**
- **SkillHub 状态：待核验**

把下面内容粘贴到 WorkBuddy 新会话：

```text
请按 https://skillhub.cn/install/skillhub.md 检查 SkillHub，搜索 `lls-colleague-skill-distiller`；仅在 slug 完全一致时安装到 `~/.workbuddy/skills/`。安装后读取 `~/.workbuddy/skills/lls-colleague-skill-distiller/SKILL.md`，核对 name、version 和实际路径，然后新开会话触发该 Skill。
```

也可以打开左侧「技能」→「添加技能 / 查找技能」，搜索 `lls-colleague-skill-distiller` 后安装；界面文字可能随 WorkBuddy 版本变化。
