# 罗老师 AI 视频脚本规划师

## 与口播稿、视频拆解的区别

- `lls-short-video-breakdown`：复盘已经存在的视频。
- `lls-douyin-oral-script-writer`：重点写真人能自然说出的口播稿。
- 本 Skill：面向制作前规划，协调旁白、镜头、字幕、素材、生成工具和后期。

## 必要输入

### 传播任务

- 给谁看；
- 希望看完理解、相信或完成什么；
- 发布平台、画幅和目标时长；
- 是独立视频还是系列中的一集。

### 内容资产

- 可核验事实；
- 用户自己的案例；
- 产品或人物素材；
- 允许使用的品牌资产；
- 必须出现或禁止出现的内容。

### 制作条件

- 真人拍摄、录屏、实拍素材、图库、动画还是生成视频；
- 可用设备、人员、地点与时间；
- 预算和截止日期；
- 目标工具支持的镜头长度、比例和提示格式。

## 规划流程

### 1. 写视频任务书

```text
受众：
当前认知：
期望变化：
一句话主张：
证据：
时长/画幅/平台：
制作方式：
成功信号：
```

### 2. 选择叙事骨架

- 教程：结果预览 → 前置条件 → 分步演示 → 常见错误 → 验收；
- 产品演示：用户困境 → 旧方法成本 → 产品动作 → 结果证据 → 下一步；
- 知识解释：具体问题 → 核心概念 → 类比 → 示例 → 应用；
- 品牌故事：人物处境 → 选择 → 阻力 → 转折 → 今天的原则；
- 案例复盘：目标 → 现场 → 决策 → 结果 → 可迁移经验。

骨架由任务决定，不把所有视频都套成“三秒钩子 + 三个技巧”。

### 3. 建立节拍表

每个节拍只推动一个变化：

| 节拍 | 时间 | 观众此刻知道什么 | 新信息 | 情绪/节奏 | 证据 |
| --- | --- | --- | --- | --- | --- |

若一个节拍没有新信息、情绪变化或必要呼吸，考虑删除。

### 4. 转成分镜

每个镜头包含：

- 镜头编号与预计秒数；
- 景别、机位和运动；
- 画面主体与动作；
- 旁白或现场声；
- 屏幕文字；
- 素材来源；
- 转场逻辑；
- 生成/拍摄备注；
- 风险与替代镜头。

镜头变化应对应信息变化，不为“高级感”无理由移动镜头。

### 5. 设计生成提示

用于图像或视频生成时，把一个镜头的提示拆成：

```text
主体 + 动作 + 环境 + 景别 + 机位 + 光线 + 色彩 + 运动 + 时长 + 画幅 + 连续性要求
```

人物连续性还要固定服装、发型、年龄段、道具、方向和场景锚点。对工具不支持的控制项标记为后期处理，不写成必然结果。

### 6. 建立素材清单

分为：

- 必拍；
- 可生成；
- 已有；
- 需授权；
- 可替代；
- 后期制作。

每项标明负责人、格式、分辨率、截止时间和版权来源。

### 7. 预演与粗剪检查

在正式制作前完成纸面预演或 animatic：

- 旁白按真实语速计时；
- 镜头总时长与目标一致；
- 画面能否独立支持旁白；
- 关键证据是否看得清；
- 静音观看是否理解主线；
- 无画面时，旁白是否仍成立。

## 输出格式

1. 视频任务书；
2. 故事骨架和节拍表；
3. 完整分镜表；
4. 旁白与屏幕文字；
5. 生成提示或拍摄说明；
6. 素材清单；
7. 制作顺序和验收清单；
8. 事实、授权和连续性风险。

## 失败处理

- 只有一个主题：先给任务书草案和三种叙事方向，不虚构案例。
- 没有画面素材：优先设计可拍的桌面演示、录屏、图表或字幕方案。
- 生成画面不稳定：减少单镜头动作，固定锚点，准备可接受的替代镜头。
- 预算太低：保留证据镜头，减少装饰性场景和复杂转场。
- 时长超标：删重复节拍，不先加速旁白。

## 质量门禁

- [ ] 受众、主张、平台、时长和制作方式清楚；
- [ ] 每个关键结论有事实、演示或案例支持；
- [ ] 分镜时长合计与目标一致；
- [ ] 镜头变化对应内容变化；
- [ ] 生成提示包含连续性锚点；
- [ ] 素材来源和授权状态清楚；
- [ ] 旁白真实计时；
- [ ] 画面、字幕和声音没有互相重复堆叠；
- [ ] 没有真实隐私、凭证或未经授权的人物素材。
