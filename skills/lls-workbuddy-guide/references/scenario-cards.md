# WorkBuddy 场景教学卡

## 通用渐隐规则

| 次数 | 教练行为 |
|---|---|
| 第一次 | 给完整启动语和三步动作 |
| 第二次 | 给 2 到 3 个选项，让用户选择 |
| 第三次 | 用户先写任务卡，教练只补遗漏 |
| 第四次 | 用户解释方法，教练检查理解 |
| 第五次 | 用户沉淀模板或 Skill，教练验收 |

## 写文档

- 启动语：请把这些资料整理成给 `[读者]` 使用的 `[文档类型]`，目标是 `[用途]`。先列结构，再写正文。
- 关键选择：读者、用途、字数、语气、引用要求。
- 验收：结构完整、事实有来源、格式符合使用场景。

## 做 PPT

- 启动语：请把这些资料整理成 `[页数]` 页 PPT 大纲，听众是 `[对象]`，目标是 `[培训/汇报/销售/答辩]`。先给目录和每页标题。
- 关键选择：听众、目标、页数、逻辑、视觉风格。
- 验收：页级结构完整、每页只有一个核心信息、素材有出处。

## 整理表格

- 启动语：请把资料整理成表格，字段是 `[字段列表]`，缺失信息写“待补充”，先给三行预览。
- 关键选择：字段、数据类型、缺失值、排序和汇总。
- 验收：字段一致、行数合理、抽查内容与原始资料一致。

## 处理 PDF

- 启动语：请先检查这个 PDF 的页数和可提取性，再将 `[目标内容]` 输出为 `[格式]`。
- 关键选择：提取、OCR、合并、拆分、翻译或表格化。
- 验收：页数、文字完整性、表格字段和原文抽查。

## 查资料

- 启动语：请查询 `[主题]`，范围是 `[地区/行业]`，时间限定为 `[时间]`，优先使用 `[来源类型]`，每条结论附直接链接。
- 关键选择：时间、范围、来源等级和交叉核验。
- 验收：链接可访问、发布日期匹配、结论得到来源支持。

## 操作网页

- 启动语：请先只读检查 `[网站/页面]`，说明准备读取和点击的内容；涉及提交动作时先等我确认。
- 关键选择：目标页面、只读或写入、登录状态、完成回执。
- 验收：最终页面读回、状态变化、截图或日志。

## 做代码或网页工具

- 启动语：请先读取项目规则和结构，为 `[功能]` 写出修改范围与验收标准，确认后实现并运行测试。
- 关键选择：项目规则、依赖、修改范围、测试和浏览器验证。
- 验收：构建、测试、关键交互、变更说明。

## 使用 SkillHub

- 启动语：请根据我的任务判断是否已有合适 Skill，并说明它的输入、输出、来源、版本和安装方式。
- 关键选择：现有 Skill、普通任务、新建 Skill、来源与版本。
- 验收：安装后触发一次真实任务，检查结果和安全报告。

## 使用企业连接器

- 启动语：请先确认目标对象和授权状态，用只读方式获取 `[对象]`；写入动作先展示将要修改的内容。
- 关键选择：真实账号、对象 ID、权限、读写范围。
- 验收：写入后重新读取正文、属性、链接或状态。
