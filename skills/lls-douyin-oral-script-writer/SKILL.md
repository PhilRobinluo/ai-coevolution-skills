# 罗老师抖音口播稿写作助手

## 核心标准

一篇合格口播稿需要同时做到：

1. 开头让目标观众马上知道“和我有关”；
2. 全篇只有一个主张；
3. 每隔几句话就有新信息或新证据；
4. 读起来像人在说，不像文章朗读；
5. 结尾给出与内容匹配的下一步；
6. 所有案例、数据和结果都来自用户提供或可核验材料。

## 开始前收集六项信息

- **目标观众**：具体到处境，不只写年龄。
- **本条主题**：一个问题或一个结论。
- **可信材料**：亲历、案例、数据、演示或出处。
- **表达目标**：建立认知、教一个方法、回应质疑、引导咨询等。
- **时长**：15 秒、30 秒、60 秒或 90 秒。
- **个人语气**：直接、温和、幽默、专业、故事型。

缺少次要信息时使用占位符；缺少主张和证据时，先整理素材，不直接编造完整稿。

## 写作流程

### 1. 写一句核心主张

格式：

```text
我希望【某类人】看完后相信或学会【一件事】。
```

一条视频不要同时讲三个结论。次要观点放到系列下一条。

### 2. 选择开头机制

开头应与正文兑现关系明确：

- 具体困境：“你每次做完 PPT，领导都说重点不清？”
- 反直觉判断：“不是你的页面不好看，是你一开始就没问对问题。”
- 结果展示：先呈现可验证的前后对比，再解释过程。
- 场景代入：用目标观众刚经历过的瞬间开场。
- 明确收益：“一分钟讲清楚怎么把会议记录变成任务表。”

禁止用和正文无关的惊吓、伪造数字或“所有人都不知道”的空钩子。

### 3. 搭建口播骨架

常用结构：

```text
相关性钩子
→ 一句主张
→ 为什么会这样
→ 一个可信证据
→ 两到三步方法
→ 回扣主张
→ 最小行动
```

故事型内容可以使用：

```text
当时的具体场景
→ 遇到的阻力
→ 错误尝试
→ 转折发现
→ 今天可以复用的原则
```

### 4. 写成嘴能说的话

- 一句表达一个意思；
- 多用具体动词和名词；
- 删除“我们可以看到”“众所周知”等书面套话；
- 专业词第一次出现时用一句通俗解释；
- 数字改成适合听觉理解的形式；
- 在自然呼吸点换行；
- 允许少量个人口头习惯，但不刻意模仿他人。

### 5. 加表演与镜头标记

使用克制标记：

```text
【近景】【停顿 0.5 秒】【重音：真正原因】【展示前后对比】
```

标记只放在影响理解或节奏的位置，不要每句都指挥表情。

### 6. 朗读计时

用正常语速完整朗读，而不是按字数猜时长。记录：

- 实际总时长；
- 第一次卡顿位置；
- 最长句；
- 证据出现时间；
- 结尾是否仓促。

超时时优先删重复和背景，不缩短关键证据。

## 常见问题

- **写得像广告**：删掉自我夸奖，增加具体问题、过程和证据。
- **开头很猛、正文接不住**：重写开头，使其只承诺正文真正交付的内容。
- **信息太多**：保留一个主张和最强证据，其余拆成系列。
- **没有个人感**：加入用户真实经历中的场景、选择和措辞，不复制网红口头禅。
- **结尾只会说关注我**：根据内容选择保存清单、尝试一步、留言问题或查看完整教程。

## 质量门禁

- [ ] 目标观众和一个主张清楚；
- [ ] 开头承诺在正文兑现；
- [ ] 事实和案例有来源；
- [ ] 没有虚假稀缺、收益或效果保证；
- [ ] 朗读时自然、句子不过长；
- [ ] 实际计时符合目标时长；
- [ ] 表演标记克制且可执行；
- [ ] 没有客户隐私、内部资料和账号凭证；
- [ ] 结尾行动与内容价值匹配。
