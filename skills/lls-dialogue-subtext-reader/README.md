# 罗老师对话潜台词解读

把聊天、会议或反馈拆成“原话事实、可能解释、未知信息和可验证回应”，避免把猜测当成读心结论。

- 版本：`1.1.0`
- 来源：🔵 LLS Original
- SkillHub：https://skillhub.cn/skills/lls-dialogue-subtext-reader
- 飞书教程：发布后补入稳定链接
- GitHub Release：发布后提供 `lls-dialogue-subtext-reader-1.1.0.zip`

## 适合谁

- 容易在聊天后反复猜测的人；
- 需要回复客户、同事、领导或亲友的人；
- 需要复盘会议、协商与冲突的人。

## 启动语

```text
请用 lls-dialogue-subtext-reader 分析下面这段对话。先把原话事实和推测分开，再给我温和版、直接版和有边界版回复。
```
