# 罗老师全能命名教练

> 类型：LLS Original  
> 当前版本：1.1.0
## 一句话用途

为项目、产品、课程、文件和 Skill 生成清楚、可搜索、能长期使用的名字。

## 什么时候使用

新建项目、仓库、课程、产品、文件或 Skill。

## 哪些情况换别的方法

已有稳定品牌且改名成本高的对象。

## 3 分钟上手

复制下面这句话给 AI：

```text
请用 lls-naming-coach，给我的中文 AI Skill 仓库起10个名字。
```

## 标准工作流程

1. **确认对象、受众和使用环境**
2. **列出必须表达与必须避开的词**
3. **生成描述型、品牌型、组合型三组候选**
4. **做搜索性、读音、长度和扩展性检查**

## 完整案例

输入：面向中文小白的AI技能仓库。

输出：三类候选、评分表、推荐名、英文slug和排除理由。

## 输出标准

最终结果至少包含：

- 用户真正要完成的任务；
- 可执行步骤，而不是只有观点；
- 关键事实、假设和未知项；
- 完成前的检查清单；
- 下一步最小动作。

## 隐私、依赖与权限

个人姓名、客户品牌和未注册商标只在用户明确要求时使用。

默认只读取用户明确提供的材料。涉及账号登录、文件写入、网络请求或外部发布时，先说明实际动作与影响范围。

## 质量检查

交付前逐项检查：

1. 是否回答了用户的真实任务；
2. 是否把事实、推断和建议分开；
3. 是否给出至少一个可复制的下一步；
4. 是否移除了本机路径、账号、密钥和客户资料；
5. 是否说明依赖、权限和失败处理。

## 常见问题

### 结果太泛怎么办？

补充目标用户、真实输入、期望输出和一个失败例子，再运行一次。

### 可以直接公开结果吗？

先检查来源、个人信息、客户内容、截图和下载链接，再决定发布范围。
