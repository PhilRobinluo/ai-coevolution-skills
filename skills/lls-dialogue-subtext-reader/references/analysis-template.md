# 对话解读模板

## 快速版

```markdown
### 能确认的事实

### 两种可能解释

### 最关键的未知信息

### 建议先问的一句话

### 可直接发送的回复
```

## 证据强度

| 强度 | 说明 |
|---|---|
| 高 | 原文明确表达时间、条件、拒绝或承诺 |
| 中 | 多个语言信号指向同一功能，但仍有其他解释 |
| 低 | 主要来自语气、回复长度或用户直觉 |

## 回应公式

### 确认

```text
我看到/听到的是【事实】。我理解为【暂定解释】，想确认一下是不是这样？
```

### 推进

```text
为了让【事项】继续推进，我建议【动作】；你更方便【选项 A】还是【选项 B】？
```

### 边界

```text
当【具体行为】发生时，会影响【具体结果】。接下来我希望我们按【边界】处理。
```
