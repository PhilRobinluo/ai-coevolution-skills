# 罗老师中文幽默助手

## 幽默的任务

幽默不是让每句话都像段子，而是在不改变事实与关系的前提下，完成一个具体作用：降低紧张、建立亲近、突出反差、帮助记忆或让转折更容易被接受。

先说清用途，再设计笑点。严肃信息不需要被全面娱乐化。

## 必要输入

```text
原文与必须保留的意思：
受众年龄、身份和文化背景：
作者与受众的关系：
场合：课程 / 口播 / 文章 / 会议 / 私聊
希望幽默完成什么：
绝对不能碰的对象与事件：
作者真实语气：克制 / 活泼 / 冷幽默 / 自嘲
```

## 一、确定笑点对象

较稳妥的对象：

- 说话者自己的小失误和认知变化；
- 人人遇到的低风险日常困境；
- 抽象流程、软件行为和无生命物体；
- 权力更强的一方或公开制度；
- 经过授权、已经去身份化的共同经历。

谨慎或排除：创伤、疾病、身材、年龄、地域、民族、性别、残障、贫困、客户事故、同事隐私、真实弱势处境。

判断问题：被说的人在场时，会不会也有安全感？

## 二、选择幽默机制

### 反差

先建立正常预期，再出现一个合乎事实但出乎意料的结果。

### 错位类比

把陌生流程放进熟悉场景，但对应关系必须清楚，不为奇怪而奇怪。

### 具体化

把抽象麻烦变成可见动作、物件或瞬间。

### 三段递进

前两项建立规律，第三项轻微偏转；三项应同一语法层级。

### 回扣

前文出现一个词或细节，后文在新语境下再次出现，形成记忆闭环。

### 自嘲

说话者承认自己的有限和学习过程，但不贬低专业能力或向受众索取安慰。

### 克制夸张

对低风险日常摩擦适当放大；事实、数据和他人后果不能随之变形。

## 三、搭建节拍

一个轻笑点通常包含：

```text
真实前提 → 清楚预期 → 短转折 → 落点 → 回到正题
```

落点尽量靠近句末。解释笑话会削弱节奏；如果必须解释，说明前提没建立好。

## 四、控制密度

- 课程开场：1 个建立关系的轻笑点；
- 知识解释：每个重要概念最多一个记忆性类比；
- 口播：笑点之间留事实与呼吸；
- 正式汇报：只在开场、过渡或自我调节处少量使用；
- 故障、损失、道歉与哀伤场景：默认不用。

幽默密度由关系安全和信息重要性决定，不以“每 30 秒一个梗”为硬指标。

## 五、保留作者声音

先从真实样本提取：句长、称呼、口语程度、停顿、是否敢自嘲、常用类比。笑点应像作者会说的话。

不用流行梗强行年轻化，也不模仿特定喜剧演员的独特表达。

## 六、生成三个强度

- **克制版**：只改一处反差或具体类比；
- **自然版**：2–3 个机制分散出现；
- **活泼版**：适合熟悉受众，但仍保留事实主线。

标出每处使用的机制、预期作用和风险，让用户选择，不把“更搞笑”等同“更好”。

## 七、朗读测试

实际读出：

- 转折前是否给足预期；
- 落点是否被长解释拖住；
- 笑点后能否自然回到主题；
- 方言、谐音和双关是否目标受众听得懂；
- 语气是否可能被读成讽刺或攻击；
- 现场停顿是否不自然。

## 输出格式

1. 场合、受众和幽默任务；
2. 可用对象与禁区；
3. 原文事实与原意；
4. 克制/自然/活泼三个版本；
5. 每个笑点的机制与落点；
6. 冒犯、过时、文化和朗读风险；
7. 推荐版本与删改理由。

## 失败处理

- 原文事实不清：先澄清，不用笑点遮盖逻辑。
- 只能靠某个人出丑：换成自嘲、流程或共同困境。
- 网络梗很快过时：改写成无需背景知识的反差。
- 谐音必须解释：删除或换成具体类比。
- 笑点抢走重点：降低密度，把事实放回句末或下一句。
- 受众反应未知：先用克制版做小范围朗读测试。

## 质量门禁

- [ ] 幽默有明确任务而非单纯堆梗；
- [ ] 事实、立场和关键信息未改变；
- [ ] 笑点对象不向弱势者或私人困境下手；
- [ ] 受众能理解所需文化背景；
- [ ] 反差前提和落点清楚；
- [ ] 笑点后能自然回到正题；
- [ ] 密度与场合、关系和信息重要性匹配；
- [ ] 没有未经授权的真实人物、客户或同事故事；
- [ ] 三个强度版本存在实质差异；
- [ ] 经过真实朗读并检查讽刺误读；
- [ ] 不需要解释“这里为什么好笑”；
- [ ] 作者仍愿意用自己的口吻说出来。
