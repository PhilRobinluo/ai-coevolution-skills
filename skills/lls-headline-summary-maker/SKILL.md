# 罗老师标题与摘要助手

## 前提

标题不是补救空内容的包装。先有已经核验的正文或视频内容，再压缩成承诺。

若源材料尚未完成，输出“暂定标题 + 需要正文兑现的清单”，不把暂定主张当事实。

## 必要输入

```text
源材料：
目标受众：
发布渠道：公众号 / 视频 / 搜索 / 报告 / 邮件 / 课程
希望读者采取的下一步：
必须保留的事实或关键词：
禁止夸大的边界：
标题长度与摘要字数：
```

## 一、提取主张地图

只从源材料提取：

- 对象：文章真正讨论谁或什么；
- 问题：受众正在面对什么；
- 新信息：材料提供了什么不同理解；
- 结果：读完后能理解或完成什么；
- 证据：案例、数据、演示或步骤；
- 限制：结果在什么条件下成立。

每个候选标题都要能指回至少一个正文段落或画面证据。

## 二、写一句核心承诺

```text
这份内容帮助【受众】在【场景】下理解/完成【具体结果】，依据是【证据或方法】。
```

标题可以省略部分信息，但不能改变承诺强度。

## 三、选择标题机制

每类先生成 2 个，不混成换词游戏：

- **直给型**：准确说明主题和收益；
- **问题型**：提出正文会真正回答的问题；
- **对比型**：展示两种方法或认知差异；
- **过程型**：强调步骤、复盘或实验；
- **结果型**：正文有可核验证据时使用；
- **对象型**：直接叫出特定受众和场景；
- **反常识型**：材料确实推翻常见认知时使用。

不用“震惊、必看、颠覆、封神、所有人都”制造未被证明的紧迫感。

## 四、做事实强度检查

逐词检查：

- “能”是否被写成“必然”；
- “一个案例”是否被写成“普遍规律”；
- “节省部分时间”是否被写成“效率提升 10 倍”；
- “方法说明”是否被写成“官方结论”；
- “尝试”是否被写成“已经成功”；
- 数字、时间和身份是否在正文中有来源。

删掉标题中无法由正文兑现的最强词。

## 五、适配渠道

### 搜索标题

核心对象和问题尽量明确，避免只写情绪悬念。

### 社交/公众号

可以增加冲突和人物，但读者点击后应在开头快速获得对应内容。

### 视频标题

与封面分工：标题给主题和承诺，封面给一个视觉焦点，不重复整句话。

### 报告/邮件

优先结论、对象、周期和所需行动，少用悬念。

## 六、写摘要

提供三个长度：

- 30–50 字：列表或分享卡片；
- 80–120 字：公众号、视频简介；
- 150–200 字：报告导语或详细介绍。

摘要结构：背景/问题 → 核心内容 → 证据或方法 → 适合谁/下一步。

摘要不得引入正文没有的新案例、数字或承诺。

## 七、评分与选择

每个标题按 1–5 分评分：

| 维度 | 问题 |
| --- | --- |
| 准确 | 正文能否完整兑现 |
| 清楚 | 受众能否一眼知道主题 |
| 相关 | 是否击中目标场景 |
| 区分 | 是否体现材料的独特内容 |
| 简洁 | 是否删除无贡献词 |
| 风险 | 是否有夸大、歧义、隐私或误导 |

推荐一个主标题，并解释牺牲了什么，不用“都很好”。

## 八、做点击后兑现测试

让审阅者只看标题和前 20% 内容，回答：

- 标题承诺是否很快被承接；
- 关键词是否与正文同义；
- 是否误以为有正文并不存在的数字、教程或案例；
- 摘要是否透露了正确范围和限制。

## 输出格式

1. 主张地图与事实边界；
2. 核心承诺；
3. 6–12 个按机制分组的候选标题；
4. 评分表；
5. 推荐标题与副标题；
6. 三种长度摘要；
7. 夸大、歧义、隐私和兑现度检查；
8. 可测试的 A/B 变量。

## 失败处理

- 只有主题没有正文：先给信息缺口和暂定方向，不生成强结果标题。
- 内容有多个中心：要求选择一个主要读者动作，其他做副标题或系列。
- 候选高度相似：更换标题机制，不只替换同义词。
- 标题清楚但平淡：增加具体对象、场景或矛盾，不增加虚假强度。
- 标题吸引但不兑现：削弱承诺或补足正文，不继续润色标题。
- 涉及客户/收入：匿名化并确认是否已经公开。

## 质量门禁

- [ ] 每个主张都能指回源材料证据；
- [ ] 目标受众、渠道和下一步清楚；
- [ ] 候选来自不同机制而非换词；
- [ ] 数字、身份、结果和时间均有来源；
- [ ] 没有把可能、案例或尝试改写成必然；
- [ ] 标题与封面/副标题有分工；
- [ ] 摘要没有新增正文不存在的事实；
- [ ] 标题在开头内容中得到及时承接；
- [ ] 推荐理由包含取舍；
- [ ] 隐私、歧义和误导风险已检查。
