# 罗老师真人化写作编辑

## 它不做什么

本 Skill 不负责“骗过 AI 检测器”，也不通过故意加错别字、口头禅或随机情绪伪装成人类。目标是提高文字的真实性、信息密度和可读性。

没有作者经历、采访或细节时，列出待补问题，不代替作者编造。

## 必要输入

```text
原稿：
用途与受众：
作者身份和关系：
必须保留的事实、数字、术语和引语：
可以删改的范围：轻改 / 结构改 / 重写
作者真实语气样本（可选）：
禁用词与隐私边界：
目标长度与是否需要朗读：
```

## 一、建立事实账本

先提取并锁定：

- 人名、组织、日期、数字；
- 因果与时间顺序；
- 直接引语；
- 作者明确观点；
- 未核验或待确认内容；
- 不能公开的私人信息。

改写后逐项对照。文风调整不授权改变事实强度。

## 二、诊断模板腔

标记具体问题而不是笼统说“AI 味”：

- 开头用大背景空转，迟迟不进入事件；
- 每段“首先、其次、最后”但内容不需要枚举；
- 大量“赋能、生态、价值、维度、意义”等抽象名词；
- 连续三个结构完全相同的句子；
- 同一结论用不同词重复；
- 没有主体的“得到提升、实现优化”；
- 无证据的“显著、极大、全面、必然”；
- 每段末尾都上升到宏大意义；
- 伪引语、伪故事和不属于作者的情绪。

每处标注“为什么妨碍理解”和“准备怎样处理”。

## 三、确定作者声音

从真实样本提取可观察特征：

- 平均句长和停顿方式；
- 常用动词与称呼；
- 直接还是委婉；
- 是否爱用例子、反问、对比；
- 专业术语密度；
- 允许的幽默程度；
- 与读者的关系。

不用“模仿某位作者”替代对特征的说明。

## 四、按层级编辑

### 第一层：事实与逻辑

修复矛盾、缺失前提、因果跳跃和强度漂移。

### 第二层：段落任务

每段只做一个主要动作：交代、证明、解释、转折、请求或收束。删除没有新任务的段落。

### 第三层：句子

恢复“谁做了什么、产生什么结果”；把抽象名词转成动作和可观察结果。

### 第四层：节奏

根据意义安排长短句、停顿和段落长度。不是随机切短，而是在重要处留呼吸。

### 第五层：词语

最后才处理套话、冗词、弱动词和重复表达。

## 五、增加具体性但不编造

可用的具体性来源：

- 原稿已经给出的动作、时间、地点和物件；
- 用户确认的真实案例；
- 可公开、可核验的数据；
- 对流程的可观察描述。

缺少细节时输出问题：

```text
这里需要一个真实瞬间：当时谁做了什么？你看到了什么结果？
```

不自动补一段“记得那天……”的虚构故事。

## 六、处理常见句型

### 抽象转动作

“提升了协作效率” → 谁少做了哪一步、等待时间怎样变化。

### 被动转主体

“问题得到解决” → 谁在何时改了什么，如何验证。

### 重复结论

保留证据最强的一次，其他位置改成推进或删除。

### 宏大收尾

回到具体下一步、限制或一个真实判断，不强行“共创美好未来”。

## 七、朗读与呼吸测试

用于演讲、口播和邮件时实际朗读：

- 一口气说不完的句子是否需要拆分；
- 连续长句是否造成疲劳；
- 重音落在真正重要的词上；
- 书面连接词是否自然；
- 读者会在哪一句失去指代对象。

记录预计时长，不靠加速完成字数目标。

## 八、交付修改证据

提供：

1. 编辑后版本；
2. 3–8 处关键修改说明；
3. 被删除的重复主张；
4. 未核验事实与待补细节；
5. 事实账本对照结果；
6. 若适用，朗读时长和卡点。

长文只展示代表性修改，不制造无价值逐字说明。

## 失败处理

- 原稿事实很少：先列采访问题，不凭空扩写。
- 用户只要轻改：保持结构，只处理明显套话、歧义和节奏。
- 作者语气样本不足：采用克制中性风格并标记假设。
- 专业文档：优先准确和术语一致，不为了“人味”口语化所有内容。
- 口播超时：删重复结论和背景，不单纯加速。
- 原稿涉及客户隐私：先匿名化，再讨论风格。

## 质量门禁

- [ ] 人名、数字、日期、引语和因果与原稿一致；
- [ ] 未核验内容仍被明确标记；
- [ ] 没有新增虚构经历、采访、情绪或身份；
- [ ] 每段有明确任务并推进内容；
- [ ] 抽象判断尽量有主体、动作或证据；
- [ ] 句子节奏服务意义，不是随机打碎；
- [ ] 作者真实语气特征被保留；
- [ ] 专业术语没有被误改；
- [ ] 朗读场景完成真实计时；
- [ ] 关键修改和待补信息对用户透明；
- [ ] 私人样本和客户原稿未进入公开资产；
- [ ] 编辑后不是另一篇“更顺滑但更空”的文字。
