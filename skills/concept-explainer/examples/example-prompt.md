# Example Prompt

```text
I am trying to use a local CLI tool, but I do not understand CLI, npm, package.json, access credentials, or environment variables.

Please help me proceed with the task. While doing that, generate short knowledge cards for the concepts I need to understand.
```

# Expected Style

```markdown
One sentence: a CLI is a text-based entrance to software; npm is the JavaScript toolbox; package.json is the project's instruction sheet.

I will first inspect the project commands, then show you the shortest safe command to run.

**Knowledge Card: CLI**
- In one sentence: a CLI is like a remote control operated by typing instead of clicking.
- In this task: it gives you a direct way to operate the tool without opening a web page.
- Remember this: a CLI is an entrance to a tool, not necessarily a separate product.
- Common mistake: thinking every command is global. Many commands must be run inside the project folder.
- Next time: if a command starts with a tool name and a verb, such as `tool login` or `tool submit`, it is probably CLI usage.
```
