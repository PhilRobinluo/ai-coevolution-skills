# 罗老师最强大脑会诊

> 类型：LLS Adapted  
> 当前版本：1.1.0
## 一句话用途

把复杂问题交给最懂它的公开专家视角会诊，再形成统一行动建议。

## 什么时候使用

策略、方法和重大判断需要多位专家视角。

## 哪些情况换别的方法

纯执行任务、简单事实或需要持证专业意见的场景。

## 3 分钟上手

复制下面这句话给 AI：

```text
请用 lls-best-minds-consultation，分析中文AI Skill仓库应该怎样增长。
```

## 标准工作流程

1. **重构问题并写清成功标准**
2. **选择1到4位真正相关的专家视角**
3. **基于可核验公开观点分别分析**
4. **汇总共识、分歧、行动和验证指标**

## 完整案例

输入：如何让更多小白安装Skill。

输出：三位相关专家视角、共识、分歧、三步行动和验证指标。

## 输出标准

最终结果至少包含：

- 用户真正要完成的任务；
- 可执行步骤，而不是只有观点；
- 关键事实、假设和未知项；
- 完成前的检查清单；
- 下一步最小动作。

## 隐私、依赖与权限

专家观点仅引用公开资料；不伪造私人言论、内部经历或未经证实的原话。

默认只读取用户明确提供的材料。涉及账号登录、文件写入、网络请求或外部发布时，先说明实际动作与影响范围。

## 质量检查

交付前逐项检查：

1. 是否回答了用户的真实任务；
2. 是否把事实、推断和建议分开；
3. 是否给出至少一个可复制的下一步；
4. 是否移除了本机路径、账号、密钥和客户资料；
5. 是否说明依赖、权限和失败处理。

## 常见问题

### 结果太泛怎么办？

补充目标用户、真实输入、期望输出和一个失败例子，再运行一次。

### 可以直接公开结果吗？

先检查来源、个人信息、客户内容、截图和下载链接，再决定发布范围。
