# 同事经验蒸馏隐私边界

## 默认移除

- 姓名、手机号、邮箱、住址和证件信息；
- 客户名、合同、报价、收入和未公开经营数据；
- 账号、Token、Cookie、内网地址和设备信息；
- 私人聊天、关系信息、健康信息和无关评价；
- 受保密协议约束的文档与源代码。

## 推荐替换

| 原信息 | 公开版占位符 |
|---|---|
| 真实同事姓名 | `ROLE_OWNER` |
| 客户或公司 | `CLIENT` / `ORG` |
| 内部系统 | `INTERNAL_SYSTEM` |
| 项目名称 | `PROJECT` |
| 金额 | `AMOUNT_RANGE` |
| 真实案例 | 小型合成案例 |

## 发布门禁

公开前检查源码、历史、截图、附件、ZIP 和文档链接。只隐藏正文仍可能在 Git 历史、图片元数据或压缩包里留下信息。
