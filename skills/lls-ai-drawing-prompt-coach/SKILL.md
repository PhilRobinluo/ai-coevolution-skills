# 罗老师 AI 绘画提示词教练

## 目标

文生图提示词不是形容词越多越好。它应当像一份给视觉创作者的短任务书，让模型知道：

- 画面要用于哪里；
- 观众第一眼看见什么；
- 正在发生哪个瞬间；
- 主体与环境如何摆放；
- 光线、颜色和材质怎样服务情绪；
- 哪些内容必须避免；
- 如何通过小步测试接近期望结果。

## 第一步：写画面意图

先完成这句话：

```text
我要为【用途】生成一张【画幅】图片，让【受众】第一眼感受到【情绪/信息】。
```

用途会影响画面：头像需要强识别主体，封面需要标题安全区，商品图需要准确形态，故事插画需要明确行动与关系。

## 第二步：固定内容骨架

### 主体

- 谁或什么是主角；
- 数量；
- 年龄段、服装、材质或产品特征；
- 当前动作；
- 面部和视线方向；
- 不可改变的识别点。

### 场景

- 时间与地点；
- 前景、中景、背景；
- 天气与环境状态；
- 与主体发生关系的道具；
- 需要留白的区域。

### 叙事瞬间

不要只写“一个人在咖啡馆”，要选择一个可见瞬间：

```text
手刚放下笔，抬头看向窗外的雨，桌上摊着写到一半的课程大纲。
```

动作、视线和道具让画面有故事。

## 第三步：设计视觉语言

### 构图

- 景别：特写、近景、中景、全景；
- 机位：平视、俯视、仰视、越肩；
- 主体位置：居中、三分法、对称、偏置；
- 视线和运动方向；
- 前景遮挡、景深和留白。

### 光线

说明光源、方向、软硬、时间和对比：

```text
清晨窗边柔光，从画面左侧进入；人物面部明亮，背景低对比。
```

### 色彩与材质

优先描述主色、辅助色、对比关系和材质表现，不写十几个颜色。材质词应能影响反射、纹理或透明度。

### 风格

选择一条主风格方向，再补两三个可观察特征，例如：

- 编辑插画：平面形状、克制纹理、清楚轮廓；
- 电影静帧：自然光、浅景深、真实材质；
- 儿童绘本：友好比例、柔和颜色、简单背景。

不直接模仿在世艺术家的独特风格；改用视觉特征描述。

## 第四步：组织提示词

推荐顺序：

```text
用途与主体
→ 动作和叙事瞬间
→ 环境与道具
→ 构图和机位
→ 光线、色彩、材质
→ 风格特征
→ 画幅与质量约束
→ 排除项
```

输出一个精简版和一个控制版。精简版用于发现方向，控制版用于收敛细节。

## 第五步：做变量实验

每一轮只更改一个主要变量：

| 轮次 | 固定项 | 改动项 | 观察结果 | 下一步 |
| --- | --- | --- | --- | --- |
| A | 主体、动作、构图 | 光线 | 情绪过冷 | 改成暖侧光 |

保留种子或参考图设置时记录下来；工具不支持的控制项标记为“不可固定”。

## 第六步：结果验收

先看语义，再看美感：

1. 主体数量和动作是否正确；
2. 关键道具和关系是否出现；
3. 构图是否适合实际用途；
4. 手、脸、文字、标志和产品结构是否异常；
5. 光线与色彩是否支持目标情绪；
6. 是否包含隐私、未经授权人物或受限品牌元素。

## 输出格式

- 画面意图；
- 必须保留与允许变化的元素；
- 精简提示词；
- 控制版提示词；
- 排除项；
- 三轮变量实验计划；
- 结果验收表；
- 针对目标工具的参数备注。

## 失败处理

- 结果太随机：减少风格词，固定主体、动作和构图。
- 画面漂亮但不传达信息：回到用途和第一视觉焦点。
- 多人物关系错误：减少人物数量，明确位置、动作和视线。
- 文字乱码：图像只留文字区域，真实文字交给排版工具。
- 角色不连续：固定识别锚点、种子、参考图和镜头方向。

## 质量门禁

- [ ] 用途、受众、画幅和第一视觉焦点清楚；
- [ ] 主体、动作和叙事瞬间可以看见；
- [ ] 风格词之间没有明显冲突；
- [ ] 构图留出实际使用空间；
- [ ] 每轮实验只改变一个主要变量；
- [ ] 最终结果按语义和视觉分别验收；
- [ ] 没有真实隐私、凭证或未经授权人物素材；
- [ ] 没有用“高清、杰作”等空词替代具体控制。
