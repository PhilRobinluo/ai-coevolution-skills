# 罗老师图片智能改名助手

- **当前源码版本：`1.1.0`**（最近 Release：`1.1.0`）

批量规划可搜索、可追溯的图片文件名，在真正改名之前检查重名、越界和引用影响。

- 来源：LLS Original
- **当前源码与 Release 版本：`1.1.0`**

- SkillHub slug：`lls-image-renamer`
- Release：https://github.com/PhilRobinluo/ai-coevolution-skills/releases/tag/lls-image-renamer-v1.1.0
