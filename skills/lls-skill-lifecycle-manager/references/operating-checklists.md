# 运行检查表

## 新建或升级

- [ ] 查重并决定新建、升级、合并、试验或跳过
- [ ] 确认 slug、显示名、用户和真实任务
- [ ] 确认来源类型
- [ ] 只修改生产母版
- [ ] 更新版本和变更说明
- [ ] `publish-info.md` 当前版本作为发布版本真源
- [ ] 校验 SKILL.md、references、scripts 和 agents
- [ ] 更新台账

## 打包

- [ ] 敏感信息扫描通过
- [ ] ZIP 只含运行文件
- [ ] ZIP 根目录为 `<slug>/SKILL.md`
- [ ] 解压测试通过
- [ ] `SKILL.md` 数量符合预期
- [ ] 脚本代表性测试通过
- [ ] SHA256 已记录

## GitHub

- [ ] 公开镜像不含内部文件
- [ ] registry 来源和版本正确
- [ ] 本地公开校验通过
- [ ] push 后 Actions 成功
- [ ] Release tag 和版本一致
- [ ] 同名 Release 存在时已比较资产哈希和源码 commit
- [ ] 公网 ZIP 返回 HTTP 200
- [ ] 下载包再次通过解压测试

## 飞书

- [ ] 用途和适用场景
- [ ] 来源标识
- [ ] 版本、源码和下载
- [ ] 启动语
- [ ] 依赖和隐私提醒
- [ ] Star / Watch / Download
- [ ] 写后读回
- [ ] 总索引已登记
- [ ] 现有页面按 node token 定位，slug 未重复

## 对账与恢复

- [ ] 平台副本按来源分类
- [ ] 以正式 Release 为基准做母库、Release、运行副本三方比较
- [ ] 独有修改先进入恢复区
- [ ] 没有自动覆盖生产母版
- [ ] 合并后重跑完整发布链
- [ ] 更新运行副本前已准备回滚，更新后已重载和触发测试

## 最终报告

- [ ] PASS / REWORK / UNCOVERED / BLOCKED 清楚
