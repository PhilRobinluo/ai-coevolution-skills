# 罗老师教育插图提示词专家

## 教育插图与普通配图的区别

普通配图可以只负责吸引注意；教育插图必须帮助学习者完成明确动作，例如识别结构、比较差异、理解顺序、解释因果或记住关系。

因此先问“看完能做什么”，再问“画成什么风格”。

## 必要输入

```text
学习者年龄/基础：
课程主题：
看图后应能完成的行为：
必须准确呈现的信息：
允许简化的部分：
使用位置与尺寸：
是否需要标注、图例或步骤编号：
品牌、版权、隐私和无障碍要求：
```

## 一、写学习目标

使用可观察动词：

- 指出植物根、茎、叶的位置；
- 按顺序复述水循环；
- 比较两种安全做法；
- 解释齿轮方向为何相反。

“让学生感兴趣”可以是辅助目标，不能替代学习目标。

## 二、拆分信息层级

把内容分成三层：

1. **必须看见**：完成学习目标不可缺少；
2. **帮助理解**：方向、编号、颜色分组、局部放大；
3. **装饰氛围**：不参与解释，可删减。

当画面拥挤时，先删第三层，不缩小关键标注。

## 三、选择插图类型

- **结构示意**：表现部分与整体，如器官、设备、地图；
- **流程图**：表现先后、循环或分支；
- **比较图**：同一尺度展示差异；
- **因果图**：用箭头和状态变化解释机制；
- **操作步骤图**：每格一个动作和检查点；
- **情境图**：让学习者判断行为、关系或问题；
- **记忆图**：用稳定意象绑定有限概念。

类型由学习动作决定，不默认用卡通人物承载所有内容。

## 四、写准确性约束

对科学、医学、历史、地理和安全主题，列出：

- 必须保持的相对位置、数量、方向和顺序；
- 示意而非真实比例的地方；
- 需要来源核验的术语和事实；
- 不得误导的颜色含义；
- 高风险内容是否需要专家复核。

生成模型适合制作视觉草案，不等于事实核验工具。

## 五、控制认知负荷

- 一张图只服务一个主要学习目标；
- 相邻放置文字与它解释的对象；
- 同一含义始终使用同一颜色和形状；
- 箭头区分“运动方向、因果关系、观察顺序”；
- 需要比较时保持视角、尺度和基线一致；
- 复杂流程拆成分步图，而不是塞进一张海报。

## 六、适龄设计

### 低龄学习者

主体少、轮廓清楚、表情友好、步骤短；避免依赖大段文字。

### 中学生

可以增加结构、变量和对比，但说明视觉编码，避免把趣味元素放在关键关系旁边。

### 成人培训

优先真实任务、证据和决策，不因“教育”就幼儿化。

适龄不等于降低事实准确性。

## 七、组织生成提示

```text
用途与学习者
→ 学习目标
→ 插图类型
→ 必须呈现的对象和关系
→ 构图、顺序与视觉层级
→ 色彩和标注安全区
→ 风格特征
→ 画幅与输出规格
→ 禁止项
```

图内真实文字、公式和精确标注优先在排版工具中后加。生成阶段可保留清晰空白标签区，避免把乱码当成成品。

## 八、建立两阶段制作

### 阶段 A：无文字视觉底图

检查对象、关系、方向、层级和留白。

### 阶段 B：人工标注与排版

添加标题、标签、编号、图例、来源和无障碍说明。标注完成后再做一次内容核验和缩略图测试。

## 九、验收测试

### 任务测试

让目标年龄的测试者只看图完成学习动作；记录误解位置，不只问“好不好看”。

### 缩略图测试

按真实课件或讲义尺寸查看，关键结构和字号仍可辨认。

### 去装饰测试

去掉背景和角色后，核心关系仍清楚。

### 准确性测试

逐项对照来源、顺序、方向、数量和标注。

## 输出格式

1. 学习者与学习目标；
2. 必须信息、辅助信息和可删装饰；
3. 插图类型与视觉结构；
4. 准确性约束；
5. 生成提示词与禁止项；
6. 后期标注清单；
7. 任务测试、缩略图测试和复核表；
8. 待确认事实和隐私/版权风险。

## 失败处理

- 画面好看但学生看不懂：回到学习动作，减少装饰并强化关系。
- 箭头含义混乱：为每类箭头定义一种视觉语法并加图例。
- 标签乱码：生成无文字底图，真实标签后期制作。
- 科学结构失真：停用生成结果作为终稿，按可靠来源重画或专家复核。
- 内容太多：拆成系列图，每张只回答一个问题。
- 低龄化过度：保留友好表达，但恢复真实概念和关键差异。

## 质量门禁

- [ ] 学习者和可观察学习目标清楚；
- [ ] 插图类型与学习动作匹配；
- [ ] 必须信息、辅助信息和装饰已分层；
- [ ] 关键位置、方向、顺序、数量和比例已核验；
- [ ] 颜色、箭头和形状含义一致；
- [ ] 真实文字与精确标注不依赖生成模型；
- [ ] 按真实使用尺寸通过缩略图测试；
- [ ] 目标学习者可以仅凭图完成指定任务；
- [ ] 图片来源、人物肖像、学生隐私和版权状态明确；
- [ ] 高风险专业内容有人工复核入口。
