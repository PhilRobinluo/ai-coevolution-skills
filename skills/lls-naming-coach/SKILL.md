# 罗老师全能命名教练

## 先定义名字承担的工作

名字可能要说明类别、表达气质、便于搜索、支持口头传播、形成系列，或满足技术 slug。一个名字不必承担所有信息；副标题、描述和视觉系统可以分工。

## 必要输入

```text
对象：产品 / 项目 / 课程 / 仓库 / Skill / 文件体系
主要受众和使用语言：
使用场景：口头、搜索、应用商店、URL、文件名
必须表达的核心：
希望的气质：
必须包含/避免的词：
长度和字符限制：
未来可能扩展到什么：
是否需要域名、商标和社媒账号：
```

## 一、写命名任务书

完成：

```text
这个名字让【受众】在【场景】中，快速联想到【类别/价值】，感受到【气质】，并能在【媒介】中正确读写和找到。
```

同时列出三个优先级最高的约束；约束过多会让候选只剩拼字游戏。

## 二、选择命名策略

### 描述型

直接说明用途，搜索和理解成本低，独特性可能较弱。

### 隐喻型

借熟悉意象表达机制或体验，需要确认文化联想一致。

### 组合型

将两个有意义词根组合，平衡说明性与独特性。

### 造词型

创造新词，便于塑造品牌，但需要教育成本和读音测试。

### 人名/地域型

强调创作者或来源，需评估隐私、扩展和团队归属。

### 系列型

建立母品牌 + 功能名规则，适合多 Skill、多课程和文件体系。

每种策略生成 3–5 个真正不同的候选，不只替换“AI、智、云”。

## 三、做语音和文字检查

- 一次听到能否复述；
- 声母、韵母是否连续拗口；
- 中文谐音和方言是否产生负面联想；
- 字形是否容易认错或输入困难；
- 英文大小写和词边界是否清楚；
- 缩写是否撞上常见机构或不良含义；
- 名称与副标题放在一起是否重复。

## 四、做使用场景测试

把候选放进真实句子：

```text
“你去 GitHub 搜索 ____。”
“我正在参加 ____ 课程。”
“请安装 Skill：____。”
“文件保存在 ____ 项目目录。”
“这是 ____ 系列的第二个产品。”
```

名字必须在使用中工作，而不只在候选列表里好看。

## 五、生成技术名称

对仓库/Skill 同时给：

- 展示名；
- 唯一 slug；
- 目录名；
- 包名建议；
- 版本标签示例。

slug 使用稳定、小写、短横线分隔的 ASCII；不要把个人路径、年份或临时状态写进长期标识，除非它们确有业务含义。

## 六、做初步可用性搜索

检查：

- 搜索引擎同名和相近领域；
- GitHub、应用商店和社媒；
- 常见域名；
- 目标国家/地区商标数据库；
- 目标语言中的含义和发音。

这些只是候选筛查，不构成商标、域名或法律权利结论。正式商用前由专业人员或对应机构核验。

## 七、建立评分矩阵

| 维度 | 说明 |
| --- | --- |
| 清楚 | 能否联想到类别或价值 |
| 好说 | 口头传播是否顺畅 |
| 好写 | 输入、拼写、slug 是否稳定 |
| 好找 | 搜索中是否容易区分 |
| 合适 | 气质是否匹配受众与场景 |
| 可扩展 | 新产品加入时是否仍成立 |
| 风险 | 负面联想、同名、权利和隐私 |

权重按项目目标确定，不用简单总分替代判断。

## 八、做盲测

向 3–5 个目标用户只展示名称，询问：

1. 你觉得它是做什么的？
2. 你会怎么读、怎么拼？
3. 你感受到什么气质？
4. 过十分钟还能记住吗？
5. 你会用什么关键词搜索它？

记录原话，不先解释名字“应该”是什么意思。

## 输出格式

1. 命名任务书和约束优先级；
2. 3–5 种策略、每种候选与构词理由；
3. 展示名、slug 和系列规则；
4. 语音、文字和真实句子测试；
5. 初步同名/域名/商标核验清单；
6. 评分矩阵；
7. 推荐名、备选名与排除理由；
8. 用户盲测计划和最终定名条件。

## 失败处理

- 用户只说“高端”：用受众、价格、场景和可观察气质追问。
- 所有候选相似：切换命名策略，不继续堆同义词。
- 好听但看不懂：增加副标题或选更描述性的候选。
- 描述型太普通：保留类别词，再增加独特意象或组合词根。
- 同名很多：记录领域和地区，重新生成而不是加随机数字。
- 个人标签限制扩展：把个人名放母品牌或署名层，功能名保持独立。

## 质量门禁

- [ ] 对象、受众、语言和使用场景明确；
- [ ] 约束有优先级而非全部同等重要；
- [ ] 候选来自多个命名策略；
- [ ] 名称能听清、说出、输入和搜索；
- [ ] 中文谐音、方言和跨语言含义已检查；
- [ ] 展示名与 slug 分工清楚；
- [ ] 名称放进真实句子后仍自然；
- [ ] 系列和未来扩展有规则；
- [ ] 初步同名、域名和商标检查有记录；
- [ ] 没有把初步搜索写成权利保证；
- [ ] 目标用户盲测使用原话记录；
- [ ] 推荐包含排除理由和最终定名条件。
