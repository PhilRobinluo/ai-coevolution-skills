## 2.0.0 自适应学习教练

- 首次接待：两分钟识别设备、任务、AI经验和练习材料。
- 学习档案：记住等级、已会能力、最近卡点和下一关。
- 五级阶梯：跟着做 → 一起做 → 自己做 → 教别人 → 沉淀工作流。
- 十关课程：从整理文字一直练到创建个人工作流或 Skill。
- 渐隐提示：同类任务越熟练，教练给出的提示越少。
- 四证验收：成品、事实、格式、外部读回。
- 三分钟复盘：用自己的话讲明白，再更新下一关。
- 错误诊断：从目标、资料、能力、执行、验收和权限六类问题定向恢复。
