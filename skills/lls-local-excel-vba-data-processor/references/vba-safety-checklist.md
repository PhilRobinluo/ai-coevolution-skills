# Excel VBA 本地处理安全清单

## 发布前代码检查

- `Option Explicit`
- 没有硬编码真实用户名和绝对路径
- 没有 `Shell`、PowerShell、网络请求或自动发信
- 没有删除原始工作表
- 没有静默覆盖同名文件
- 成功与失败都恢复 Excel 状态
- 输入范围、表头和工作表均有检查
- 错误信息包含步骤，不输出敏感数据

## 最小验收表

| 测试 | 输入 | 期望 |
|---|---|---|
| 正常 | 三条合法记录 | 三条成功 |
| 空值 | 唯一键为空 | 进入错误清单 |
| 重复 | 两条相同唯一键 | 按数据契约处理 |
| 格式错 | 非法日期/金额 | 不写入正式结果 |
| 无匹配 | 查找表中不存在 | 标记未匹配 |

## 回滚

1. 关闭当前测试副本；
2. 保留日志和错误清单；
3. 从运行前备份重新复制一份；
4. 修正规则或宏；
5. 用同一组测试案例复测。
