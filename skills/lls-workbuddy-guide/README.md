## 三端闭环

```text
SkillHub 发现与安装
        ↓
飞书教程、案例、启动语与常见问题
        ↓
GitHub 源码、Release、Star 与 Watch
        ↓
回到 SkillHub 使用新版 Skill
```

三个入口互相连接：

- **SkillHub**：让用户发现、查看和安装 Skill。
- **飞书**：把 Skill 讲明白，提供中文教程、案例和推荐启动语。
- **GitHub**：保存公开源码、版本记录和独立安装包。
