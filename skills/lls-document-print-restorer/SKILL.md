# 罗老师纸质文件打印修复助手

> 类型：LLS Original  
> 当前版本：1.1.0
## 一句话用途

保守增强拍摄的纸质文件照片，并生成A4打印版PDF。

## 什么时候使用

纸质表格、票据或手写页照片偏灰、对比度低、打印不清。

## 哪些情况换别的方法

需要恢复法律意义上的缺失文字或重制公章、签名。

## 3 分钟上手

复制下面这句话给 AI：

```text
请用 lls-document-print-restorer，把这张表格照片做成A4打印版。
```

## 标准工作流程

1. **检查模糊、阴影、折痕和裁切问题**
2. **优先使用确定性对比度与锐化**
3. **需要AI修复时限制为视觉增强且禁止补字**
4. **生成A4 PDF并人工核对关键数字**

## 完整案例

输入：偏灰但内容基本可见的签收表。

输出：增强JPG、A4 PDF、关键数字复核提醒。
