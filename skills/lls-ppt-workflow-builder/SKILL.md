# 罗老师 PPT 全流程构建器

## 它解决什么问题

很多 PPT 失败不是因为页面不好看，而是没有回答：

- 这场演示结束后，希望谁做什么决定？
- 听众现在相信什么、担心什么？
- 哪些材料是事实，哪些只是观点？
- 每一页在整条故事线里承担什么任务？

本 Skill 把 PPT 当成一次“推动理解与决策的产品交付”，而不是图片和文字的堆叠。

## 七个阶段

```mermaid
flowchart LR
  A["明确场景"] --> B["审计材料"]
  B --> C["建立故事线"]
  C --> D["设计逐页任务"]
  D --> E["制定视觉规范"]
  E --> F["制作与校对"]
  F --> G["演练与验收"]
```

### 阶段一：明确场景

一次只收集决定结构的关键事实：

1. 演示对象是谁，人数和角色是什么？
2. 现场汇报、在线发送还是两者兼有？
3. 可用时间、目标页数和截止时间？
4. 听众最后需要理解、相信或批准什么？
5. 哪些表达受品牌、保密或合规限制？

输出一份演示合同：

```text
主题：
核心听众：
当前认知：
期望决策：
演示时长：
成功信号：
限制条件：
```

### 阶段二：审计材料

将原始材料分为四类：

- **可引用事实**：有来源、有日期、可核验；
- **内部判断**：需要标明假设或负责人；
- **视觉素材**：图片、图表、品牌资产及使用权限；
- **缺口**：决定故事线但当前没有的信息。

不得为了填满页面虚构数据、案例、客户评价或来源。

### 阶段三：建立故事线

先写一页纸，不立刻做幻灯片。根据场景选择结构：

- 决策汇报：现状 → 问题 → 证据 → 方案 → 取舍 → 请求；
- 项目复盘：目标 → 发生了什么 → 原因 → 学到什么 → 下一步；
- 教学分享：问题 → 概念 → 示例 → 练习 → 总结；
- 产品介绍：用户痛点 → 价值主张 → 工作方式 → 证据 → 行动。

整套演示只能有一个主结论。每个章节必须能解释它与主结论的关系。

### 阶段四：设计逐页任务

每页先写页面任务，再写内容：

| 字段 | 说明 |
| --- | --- |
| 页码 | 稳定编号 |
| 结论式标题 | 读标题就知道本页观点 |
| 页面任务 | 这页要让听众理解或决定什么 |
| 核心证据 | 数据、案例、引用或演示 |
| 推荐视觉 | 图表、流程、对比、照片或大字 |
| 讲者备注 | 页面之外需要口头补充什么 |
| 来源 | 文件、网址、访谈或内部负责人 |

一页只保留一个主要信息动作。需要两分钟解释的表格，先拆解或突出结论。

### 阶段五：制定视觉规范

在页面制作前锁定：

- 画布比例与安全边距；
- 字体、字号层级和中英文字体替代；
- 主色、强调色、状态色；
- 图片比例、裁切方式与版权要求；
- 图表的数字格式、坐标轴和来源位置；
- 页码、标题、脚注和品牌元素规则。

视觉规则要服务信息层级。不要用十种版式证明“设计感”。

### 阶段六：制作与校对

建议顺序：

1. 先制作三张代表页：封面、典型内容页、复杂图表页；
2. 确认方向后批量展开；
3. 每五页做一次内容和视觉回看；
4. 导出 PDF 检查字体、换行、图片和透明效果；
5. 对数字、专有名词、页码、来源做机械校对。

程序化生成 PPT 时，还要检查元素越界、重叠、缺图、字体替换和导出结果。

### 阶段七：演练与验收

- 按真实时长完整讲一遍；
- 记录每页耗时和卡顿位置；
- 准备 3–5 个最可能的问题；
- 检查离线文件、字体、视频和备用 PDF；
- 让不熟悉项目的人只看标题，复述故事线；
- 根据反馈删页优先于加页。

## 输出物

根据用户需求交付其中一项或多项：

- 演示合同；
- 材料与证据台账；
- 一页纸故事线；
- 逐页脚本表；
- 视觉规范；
- 可制作的 PPTX；
- 演练记录与验收报告。

## 失败处理

- **资料太多**：先按“与决策目标的相关性”排序，不直接摘要全部文件。
- **没有数据**：将论点标成待验证假设，并设计最小取证动作。
- **时间过短**：保留主结论、三条证据和明确请求，其他移到附录。
- **用户只说‘高级一点’**：用受众、场景、品牌和参考样例把抽象审美变成可检查规则。
- **自动生成结果拥挤**：先修故事和信息密度，再调字号；不靠缩小文字硬塞。

## 质量门禁

- [ ] 演示对象、时长、场景和决策目标已明确；
- [ ] 主结论只有一个；
- [ ] 每页标题表达结论，而不是仅写主题；
- [ ] 关键事实有来源，推断有标记；
- [ ] 图表单位、日期和口径一致；
- [ ] 没有真实账号、凭证、内部绝密材料；
- [ ] PDF 导出抽查通过；
- [ ] 完整演练时长达标；
- [ ] 最终请求或下一步清楚可执行。

详细交付表见 [references/delivery-checklist.md](references/delivery-checklist.md)。
