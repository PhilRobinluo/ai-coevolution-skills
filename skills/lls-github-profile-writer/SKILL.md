# 罗老师 GitHub 首页助手

> 类型：LLS Original  
> 当前版本：1.0.0

## 一句话用途

把GitHub个人主页或仓库README写成访客快速看懂、愿意使用和收藏的门面。

## 什么时候使用

新建或升级GitHub主页、项目README和开源作品集。

## 哪些情况换别的方法

仓库还没有可运行内容或真实交付物。

## 3 分钟上手

复制下面这句话给 AI：

```text
请用 lls-github-profile-writer，重写这个Skill仓库首页。
```

## 标准工作流程

1. **确认目标访客和一个核心价值**
2. **把首屏写成价值、入口、代表作和Star引导**
3. **补安装、示例、来源、维护状态**
4. **检查所有链接、命令和下载入口**

## 完整案例

输入：包含6个中文Skill的仓库。

输出：首屏、能力目录、安装、来源政策、Star与Watch引导。

## 输出标准

最终结果至少包含：

- 用户真正要完成的任务；
- 可执行步骤，而不是只有观点；
- 关键事实、假设和未知项；
- 完成前的检查清单；
- 下一步最小动作。

## 隐私、依赖与权限

README示例使用公开资料；移除私人邮箱、内网地址和本机路径。

默认只读取用户明确提供的材料。涉及账号登录、文件写入、网络请求或外部发布时，先说明实际动作与影响范围。

## 质量检查

交付前逐项检查：

1. 是否回答了用户的真实任务；
2. 是否把事实、推断和建议分开；
3. 是否给出至少一个可复制的下一步；
4. 是否移除了本机路径、账号、密钥和客户资料；
5. 是否说明依赖、权限和失败处理。

## 常见问题

### 结果太泛怎么办？

补充目标用户、真实输入、期望输出和一个失败例子，再运行一次。

### 可以直接公开结果吗？

先检查来源、个人信息、客户内容、截图和下载链接，再决定发布范围。
