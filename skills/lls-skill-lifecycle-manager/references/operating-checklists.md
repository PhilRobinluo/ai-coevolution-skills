# 运行检查表

## 选库与隔离

- [ ] 已明确本轮唯一写入库：私有母库或公开分享库
- [ ] 没有把另一仓库设为复制源、构建输入或脚本参数
- [ ] 没有子模块、共享 worktree、符号链接、镜像或一键公开
- [ ] 公开任务仅使用公开资料和公开版测试夹具

## 新建或升级

- [ ] 在选定仓库内查重并决定新建、升级、合并或跳过
- [ ] 确认 slug、显示名、用户、来源类型和真实任务
- [ ] 只修改当前仓库自己的真源
- [ ] 更新该仓库自己的版本和变更说明
- [ ] 校验 SKILL.md、references、scripts 和 agents

## 许可证

- [ ] 原创内容标为 `CC-BY-NC-SA-4.0`
- [ ] 含实质 `scripts/` 时同时标为 `PolyForm-Noncommercial-1.0.0`
- [ ] 第三方或改编内容保留上游许可证与来源
- [ ] 企业内部额外许可和商业授权入口清楚
- [ ] 历史 MIT 版本边界已记录

## 打包

- [ ] 敏感信息扫描通过
- [ ] ZIP 只含当前 Skill 运行文件与许可证
- [ ] ZIP 根目录为 `<slug>/SKILL.md`
- [ ] 解压测试和代表性脚本测试通过
- [ ] SHA256 已记录

## GitHub、飞书与 SkillHub

- [ ] 当前目录和 remote 都属于公开分享库
- [ ] 公开 registry 的来源、许可证和版本正确
- [ ] push 后 Actions 成功
- [ ] Release tag、ZIP、SHA256 和源码版本一致
- [ ] 飞书页面写后读回
- [ ] SkillHub 最终提交仍保留逐版本确认

## 对账与恢复

- [ ] 平台副本按所属真源分类
- [ ] 以所属仓库正式版本做三方比较
- [ ] 独有修改先进入恢复区
- [ ] 没有跨库覆盖或批量倒灌
- [ ] 更新运行副本前已准备回滚，更新后已触发测试

## 最终报告

- [ ] PASS / REWORK / UNCOVERED / BLOCKED 清楚
- [ ] 每个 PASS 有命令、链接、日志或读回
- [ ] 残余风险真实
- [ ] 下一次升级动作明确
