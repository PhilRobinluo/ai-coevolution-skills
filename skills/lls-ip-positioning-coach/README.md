## 一句话启动

```text
请用罗老师 IP 定位教练带我一步步完成定位。一次只问一个阶段，最后给出 3 个明显不同的方案、风险和未来 7 天验证动作。
```

## 核心特点

- 一次只推进一个阶段，降低新手的理解压力。
- 明确区分用户事实与 AI 推断。
- 方案包含目标用户、内容支柱、可信度、商业入口和风险。
- 不做虚假履历、夸张人设和快速赚钱承诺。
