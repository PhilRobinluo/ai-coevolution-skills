## Skill 生产与进化工具链精选

这三项属于罗老师推荐，不是罗老师原创或改编。仓库只做中文解释和上游导航。

### dot-skill（同事.skill）

- 作者：titanwings
- 用途：蒸馏同事、导师、关系对象或公众人物的能力与表达特征。
- 罗老师推荐理由：适合把“一个人怎么做事”整理成可复用 Skill；同事路线应先处理资料授权、客户信息和内部系统数据。
- 原始仓库：https://github.com/titanwings/colleague-skill/tree/dot-skill
- 许可证：MIT
- 核验提交：`47039d0`
- 分发：只链接上游。

### nuwa-skill（女娲.skill）

- 作者：Huashu（花叔）
- 用途：从公开资料中提取人物或主题的心智模型、判断方法和表达结构。
- 罗老师推荐理由：重点不是模仿口头禅，而是把公开思想整理成有证据、有边界的认知 Skill。
- 原始仓库：https://github.com/alchaincyf/nuwa-skill
- 许可证：MIT
- 核验提交：`27642f5`
- 分发：只链接上游。

### darwin-skill（达尔文.skill）

- 作者：alchaincyf（花叔）
- 用途：用测试和实验循环评估、改进已有 Skill。
- 罗老师推荐理由：把“凭感觉改 Skill”升级成有基线、有测试、有保留或回退记录的进化流程。
- 原始仓库：https://github.com/alchaincyf/darwin-skill
- 许可证：MIT
- 核验提交：`2fbaf41`
- 分发：只链接上游。
