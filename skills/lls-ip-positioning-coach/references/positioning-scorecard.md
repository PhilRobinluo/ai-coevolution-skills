# IP 定位评分卡

每个候选方向按 1–5 分评分，并写出证据。没有证据时记为“待验证”，不要为了得出结论虚构分数。

| 维度 | 判断问题 |
| --- | --- |
| 长期兴趣 | 用户愿意连续两年研究和表达吗？ |
| 可信能力 | 有经历、成果、作品或第三方反馈支持吗？ |
| 用户痛点 | 目标用户是否频繁遇到这个问题？ |
| 内容持续性 | 能否拆出至少 30 个不重复选题？ |
| 差异化 | 经历、方法、对象或表达是否有清楚区别？ |
| 低成本验证 | 七天内能否用内容、访谈或小服务得到反馈？ |
| 商业连接 | 是否存在自然、克制的服务或产品入口？ |
| 风险可控 | 是否避开虚假承诺、隐私和专业越界？ |

## 推荐规则

1. 不只看总分，先淘汰“可信能力低于 3”或“用户痛点低于 3”的方向。
2. 若两个方向接近，优先选择七天内更容易验证的一个。
3. 初次定位是阶段性假设，不是永久身份；用真实反馈迭代。
