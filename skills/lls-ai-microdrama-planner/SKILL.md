# 罗老师 AI 漫剧与短剧策划专家

## 它解决什么

本 Skill 把“有一个爽点”变成可以生产、能连载、前后不打架的短剧方案。重点不是一次写出大量台词，而是先建立稳定的故事发动机：

- 主角长期想得到什么；
- 每一集什么阻力迫使他选择；
- 选择产生什么代价；
- 结尾留下哪个必须继续看的未决问题；
- 角色、场景和道具怎样跨镜头保持一致。

## 必要输入

```text
发行形态：真人短剧 / 漫剧 / 动态漫画 / 生成视频
目标平台与单集时长：
核心受众与情绪承诺：
题材与世界边界：
计划集数：
可用人物、场景和资产：
制作工具与限制：
必须避开的内容：
```

缺少信息时先给“待确认清单”，不要把假设写成既定设定。

## 一、定义观众承诺

用一句话说明观众为什么持续看：

```text
让【某类观众】持续获得【情绪/认知体验】，并追问【长期悬念】。
```

承诺应可在多集兑现。只靠第一集猎奇、后续无法重复的点子不是系列承诺。

## 二、建立故事发动机

### 主角卡

- 表面目标：当前主动追求什么；
- 深层需要：他尚未承认的改变；
- 能力与短板：解决问题的方法为什么也会制造问题；
- 底线：什么选择最能暴露人物；
- 可见识别点：服装、道具、动作或语言习惯。

### 对抗卡

对手不只是“坏人”，还应有合理目标、资源和施压方式。写清：

```text
对手要什么 → 为什么与主角冲突 → 能施加什么代价 → 哪一点可能动摇
```

### 冲突循环

主角采取行动 → 暂时得失 → 新信息出现 → 代价升级 → 被迫做更难的选择。

每次循环至少改变“信息、关系、资源、时间压力”中的一项。

## 三、设计季节弧线

建立四张表：

1. 世界与规则：什么可能、什么绝对不可能；
2. 关系弧：主要人物从何种关系走向何种关系；
3. 悬念账本：提出时间、线索、预计回收点；
4. 代价曲线：失败的后果怎样逐步加重。

中途新增设定时，先检查是否与既有事实冲突。

## 四、规划单集节拍

一个短集可以采用以下功能节拍，而不是机械按秒套模板：

1. **状态变化**：开场立刻呈现异常、后果或进行中的行动；
2. **本集目标**：主角必须在什么期限前完成什么；
3. **第一次受阻**：原计划为什么失效；
4. **主动选择**：主角做出有代价的决定；
5. **局面翻转**：新事实改变对局理解；
6. **结果与欠账**：本集有局部结果，同时产生新问题；
7. **结尾钩子**：用行动、发现或决定打开下一集。

钩子必须源自本集因果，不用无关人物突然出现硬切。

## 五、从节拍到场景

每个场景写一张卡：

```text
场景任务：
进入时的局面：
谁想要什么：
阻力：
关键行动：
转折信息：
离开时的变化：
所需人物/场景/道具：
```

若场景结束后信息、关系、资源和风险都没变化，优先合并或删除。

## 六、写台词与视觉动作

- 台词服务行动，不把人物已经做出的动作再解释一遍；
- 能用表情、位置、道具和停顿表达的，不全部交给旁白；
- 每个角色的句式、语速和回避方式要区分；
- 重要信息先决定“谁在何种压力下说出”，再润色句子；
- 漫剧气泡控制长度，给画面留出表演空间。

## 七、建立 AI 制作连续性

为主要角色和场景建立锚点：

- 外貌、服装、配色、比例；
- 左右方向、惯用手和关键道具；
- 场景布局、时间、天气与光线；
- 镜头前后的情绪与受伤状态；
- 可变化项与不可变化项。

生成提示一次描述一个镜头的主体、动作、环境、景别、机位、光线和连续性锚点。工具不支持稳定控制时，准备替代镜头或后期修正，不承诺必然一致。

## 输出格式

1. 项目任务书与观众承诺；
2. 人物、对抗与世界规则；
3. 季节弧线和悬念账本；
4. 逐集一句话目标、转折与钩子；
5. 目标集的节拍表和场景卡；
6. 台词草案与镜头资产清单；
7. 连续性表；
8. 风险、待确认项和制作验收。

## 失败处理

- 只有题材：给三种冲突发动机，不直接虚构完整季。
- 情节靠巧合：把关键转折改成角色选择的后果。
- 每集都在重复：检查本集是否改变关系、信息、资源或风险。
- 反转太多：保留会改变人物决策的反转，删除只求惊讶的反转。
- AI 画面不稳定：减少同镜头人物和动作，固定锚点并拆镜头。
- 时长超标：先删解释性台词和重复场景，不把全片加速。

## 质量门禁

- [ ] 观众承诺、平台、单集时长和制作形态清楚；
- [ ] 主角有长期欲望、短板和必须付出的代价；
- [ ] 每集有独立局部结果，又推进长期弧线；
- [ ] 关键转折来自选择与因果，不依赖随机巧合；
- [ ] 悬念有账本，重要问题有计划回收；
- [ ] 场景结束后至少一个故事状态发生变化；
- [ ] 台词、动作和旁白没有重复解释；
- [ ] 人物、场景和道具有连续性锚点；
- [ ] 素材版权、真人肖像和隐私状态明确；
- [ ] 未确认设定与已发生事实清楚分开。
