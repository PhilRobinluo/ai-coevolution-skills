# 罗老师 AI 海报设计教练

## 海报首先是信息产品

海报成功的第一标准不是“看起来高级”，而是目标人群在正确场景下能迅速完成：

1. 看见；
2. 看懂；
3. 相信；
4. 知道下一步做什么。

因此先处理信息和行动，再处理风格。

## 一、建立传播任务书

```text
投放场景：
画布尺寸/比例：
目标人群：
他们此刻最关心什么：
唯一主信息：
必须完成的行动：
必要事实：
品牌与合规限制：
截止时间：
```

线上信息流、朋友圈长图、线下打印和课程封面需要不同字号、距离和信息密度。

## 二、清理内容

将材料分为四层：

### 第一层：三秒内要看见

- 主题或结果；
- 与受众的相关性；
- 核心视觉。

### 第二层：决定是否继续看

- 一到三个价值点；
- 可信证据；
- 时间、地点或适用对象。

### 第三层：采取行动前确认

- 价格、报名条件、截止时间；
- 二维码、网址或联系入口；
- 必要免责声明。

### 第四层：移出海报

详细课程大纲、长段背景、完整政策和次要故事放到落地页或说明文档。

## 三、写海报文案

- 主标题尽量表达一个结果、问题或活动事实；
- 副标题解释对象、范围或差异；
- 卖点使用平行结构；
- 数据必须保留口径和来源；
- 行动文案说明“做什么”，不只写“立即行动”；
- 避免虚假紧迫、绝对收益、无法证明的第一或唯一。

输出主标题至少三个方向：直接型、问题型、结果型。每个方向说明适合的受众心理。

## 四、设计版式骨架

先用灰度框架确认层级：

```text
品牌/栏目
主标题
副标题
核心视觉
价值点或证据
时间地点/价格
行动区
必要脚注
```

检查：

- 视线是否自然落到标题和行动区；
- 同一层信息是否有统一字号；
- 边距和间距是否形成分组；
- 二维码是否有安静区；
- 手机缩略图中主标题是否可读；
- 打印是否考虑出血和裁切。

## 五、选择视觉方向

视觉方向要写成可以执行的规则：

| 项目 | 决策 |
| --- | --- |
| 核心视觉 | 人物、产品、场景、图形或字体 |
| 构图 | 居中、对角、分栏、留白 |
| 色彩 | 主色、强调色、背景与对比 |
| 字体 | 标题、正文、数字层级 |
| 图像 | 摄影、插画、3D、抽象图形 |
| 质感 | 克制、活力、可信、亲切等 |

需要生成图片时，只生成没有正文文字的视觉素材，预留标题和行动区；最终文字在专业排版工具中完成。

## 六、制作三个候选方案

三个方案必须在信息策略或构图上有真实差异：

- A：信息直接，适合快速转化；
- B：场景和故事更强，适合建立情绪；
- C：证据和品牌更强，适合专业信任。

不要只换背景颜色就称为三个方案。

## 七、导出验收

### 屏幕版

- 实际像素尺寸；
- sRGB；
- 文件体积；
- 缩略图可读性；
- 二维码真机扫描；
- 深色和浅色屏幕抽查。

### 印刷版

- 成品尺寸和出血；
- CMYK 或印厂要求；
- 图片有效分辨率；
- 字体嵌入或转曲；
- 黑色、小字和细线；
- PDF 输出预检。

## 输出格式

- 传播任务书；
- 信息层级清单；
- 三组标题与精简文案；
- 灰度线框；
- 三个视觉方向；
- 推荐方案与理由；
- 生成素材提示词；
- 线上或印刷导出清单；
- 来源、版权和合规风险。

## 质量门禁

- [ ] 一个海报只有一个主信息和一个主要行动；
- [ ] 主标题在目标观看距离可读；
- [ ] 关键信息没有被装饰遮挡；
- [ ] 真实文字由排版工具完成；
- [ ] 数据、图片和字体来源可追溯；
- [ ] 二维码实际扫描通过；
- [ ] 没有客户隐私、内部凭证或未经授权肖像；
- [ ] 导出规格与投放场景一致。

验收表见 [references/poster-acceptance.md](references/poster-acceptance.md)。
